# Reglas de escritura y validación

## Regla crítica

Ningún trabajador puede sacar texto si contiene cualquiera de estos patrones:

- `Ã`
- `Â`
- `â`
- `??`
- `?n`
- `?a`
- `?o`
- `?as`
- `?os`
- `m?s`
- `Direcci?n`
- `Automatizaci?n`
- `P?ginas`
- `M?tricas`

## Lista negra visual

## Checklist obligatorio antes de publicar

1. revisar ortografía
2. revisar acentos
3. revisar caracteres rotos
4. revisar CTA
5. revisar beneficio
6. revisar coherencia con marca

## Responsables de validación

- caption_editor
- copy_chief
- copy_senior_community
- copy_senior_seo
- copy_senior_web
- copy_senior_sales

## Regla operativa

Si un texto falla:

- no se publica
- no se sube a web
- no se usa en SEO
- no se usa en GEO
- no se usa en AEO
- se corrige primero
